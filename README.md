# HarnessAI Beta source archive

`HarnessAI-Beta-source-2f38f3b.zip` is encrypted with AES-256, including the names of the
files inside it. The password is provided separately.

SHA-256: `2e3e755211a81738ba096bb312ba6f67624c8707f259043eef6884d906136245`

## Opening it

It opens in two steps: the password unlocks `source.zip`, which then opens like any zip.

- **macOS:** in Terminal, run `tar -xf HarnessAI-Beta-source-2f38f3b.zip`, enter the password
  when it asks, then double-click `source.zip`. Keka or The Unarchiver also work.
- **Windows:** open it with 7-Zip, then open `source.zip` normally.
- **Linux:** `7z x HarnessAI-Beta-source-2f38f3b.zip` (p7zip) or `bsdtar -xf`, then `unzip source.zip`.

Some built-in unzip tools can't open AES-encrypted zips. Use one of the tools above.
